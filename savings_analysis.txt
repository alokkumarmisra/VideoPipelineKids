=== KEY BENEFIT ===

The universal prompt is STORY-AGNOSTIC - works for ANY new project without rehardcoding:

1. CHANGE GENRE: Set genre to "Devotional", "Sci-Fi", "Action", "Comedy", "Drama", etc.
2. CHANGE STYLE: Set style to "Indian Mythological", "Cinematic", "Flux Reference Image", "Wan 2.1 I2V", etc.
3. CHANGE SOURCE LINES: Any number of lines in any language (Hindi, English, Hinglish, regional)
4. CHANGE TOTAL SECONDS: Any audio runtime (60s, 120s, 300s, 600s, etc.)
5. CHANGE BATCH SECONDS: Any batch size (15s, 30s, 45s, 60s, 90s, etc.)

=== HOW IT WORKS ===

1. System message: universalSystemPrompt (3200 chars - story-agnostic)
2. User message: project-specific JSON with title, genre, style, source_lines, total_seconds, batch_seconds
3. LLM outputs: scene plan JSON matching the schema (unchanged across projects)
4. All 20+ rules preserved universally - no story-specific hardcoding

=== RULES PRESERVED UNIVERSALLY ===

- Scene 1 identity free (abstract only)
- Source-led scene boundaries
- Source-grounded visuals (no pulling later chars back)
- Narration preservation (exact source verbatim)
- Dialogue disabled ([] on every scene)
- Visual quality production-ready
- Video prompt: movement only, no appearance
- Meaning variation (ONE concrete action per flagged line)
- Multi-shot handling (2-5 shots per scene)
- Anatomy-safe staging (limbs species-appropriate only)
- ID rules (valid location/character/object ids)
- Output language (Hindi story, English prompts)
- Continuity (scene-to-scene connection)
- Approved asset rule (asset_refs with bible IDs)
- Flagged lines handling (no placeholder text)

=== INPUT FORMAT FOR NEW PROJECTS ===

{
  "title": "NEW PROJECT TITLE",
  "genre": "[GENRE]",
  "style": "[STYLE]",
  "total_seconds": [TOTAL_AUDIO_SECONDS],
  "batch_seconds": [BATCH_SECONDS],
  "source_lines": [
    "LINE 1 IN SOURCE LANGUAGE",
    "LINE 2 IN SOURCE LANGUAGE",
    // ... any number of lines
  ],
  "language": "[HINDI/ENGLISH/OTHER]",
  "flags": ["abstract_openings", "meaning_variation", "any_other"]
}

=== OUTPUT FORMAT (IDENTICAL ACROSS ALL PROJECTS) ===

JSON with scenes array containing:
- scene_number, title, line_from, line_to, narration, dramatic_purpose
- duration_seconds, characters[], location, objects[], asset_refs
- time_of_day, action, motion, emotion, expression, body_language
- camera{(shot_type/angle/movement)}, lighting, environment
- continuity_from_previous_scene, transition_to_next_scene, dialogue[]
- image_prompt="", video_prompt="", shots[]
